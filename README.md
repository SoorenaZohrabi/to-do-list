# To-Do List App

## Description

A responsive to-do list application built with HTML, Sass, and JavaScript that allows users to create, manage, and organize tasks with persistent client-side storage using IndexedDB.

This project focuses on building an interactive task management application while improving my understanding of:

* JavaScript ES6 modules and classes
* Object-oriented programming (OOP)
* IndexedDB for browser-based data persistence
* DOM manipulation and event handling
* Sass for writing maintainable and modular styles
* Responsive web design

## Technologies Used

* HTML5
* Sass (SCSS)
* JavaScript (ES6 Modules)
* IndexedDB
* Font Awesome

## Features

* Add tasks with a title, due date, and custom background color
* Persist tasks using IndexedDB
* Toggle tasks between Active and Completed
* Filter tasks by All, Active, or Completed
* Delete tasks from the task list
* Responsive design for desktop, tablet, and mobile devices
* Modern UI with animations, custom colors, and hover effects

## Purpose

This project is part of my frontend development and JavaScript learning journey to strengthen my understanding of object-oriented programming, browser storage with IndexedDB, Sass-based styling, DOM manipulation, and building responsive, interactive web applications using vanilla JavaScript.
